ADRENAL hydrocortisone re-design (binary endpoint)

Five-look Bayesian GSD on the risk-difference scale. Section 5.2 of the manuscript.

Setting

The ADRENAL trial (Venkatesh et al., NEJM 2018;378:797–808) was a multicentre, placebo-controlled, double-blind, randomised clinical trial of hydrocortisone versus placebo in patients with septic shock. The primary endpoint was 90-day all-cause mortality. With a 33% mortality rate in the placebo arm, the trial was powered to detect an absolute risk reduction of 5% at a two-sided 5% significance level, which required a maximum sample size of 3,800 (1,900 per arm with 1% dropout).

Bayesian GSD re-design

We re-implement the trial as a five-look Bayesian GSD (K = 5), with looks equally spaced at n = 380, 760, 1,140, 1,520, 1,900 patients per arm, independent Beta(1, 1) priors on the per-arm rates, a single-criterion efficacy rule ℙ(Δ < 0 | ·) > 0.99 on the risk-difference scale, and a futility rule ℙ(Δ > 0 | ·) > 0.90.

adabay call sequence

Design, prior and decision rule

library(adabay)

des <- set_design(endpoint     = "binary",
                  n_per_look   = c(760, 1520, 2280, 3040, 3800),
                  effect_scale = "risk_difference",
                  alternative  = "less")

pri <- set_prior(endpoint = "binary",
                 arms = list(c = list(family = "beta", a = 1, b = 1),
                             t = list(family = "beta", a = 1, b = 1)))

dec <- set_decision(
  efficacy = list(list(threshold_effect = 0, threshold_prob = 0.99)),
  futility = list(list(threshold_effect = 0, threshold_prob = 0.90)),
  futility_binding = TRUE)

oc_h0 <- evaluate_design(des, pri, dec,
                         effect   = list(theta_c = 0.33, theta_t = 0.33),
                         n_trials = 1e6, cores = 8, seed = 1L)
oc_h1 <- evaluate_design(des, pri, dec,
                         effect   = list(theta_c = 0.33, theta_t = 0.28),
                         n_trials = 1e6, cores = 8, seed = 1L)

adabay runs on 8 CPU cores via mclapply with the L'Ecuyer combined multiple-recursive generator (cores = 8); adaptr on 8 cores via its native parallel backend; BATSS with 8 mclapply workers and INLA pinned to one thread per worker. Since the three simulation-based packages all run on 8 cores at the matched R = 10,000 budget, their wall-clock times are directly comparable at equal parallelism: the per-virtual-trial speedups on the binary case are approximately 39× versus adaptr (between one and two orders of magnitude) and 2.0 × 104 × versus BATSS (four orders of magnitude). “n/a” marks comparators that do not support this endpoint type (gsbDesign is restricted to the normal–normal continuous setting).

Threshold calibration

Section 6.3 of the manuscript evaluates stage-specific Haybittle–Peto-style designs from a single cache. The five-look design with efficacy thresholds p1:5 = (0.997, 0.997, 0.997, 0.997, 0.980) and common futility threshold q = 0.85 has type I error 2.42% and power 90.18%, meeting the regulatory targets α ≤ 2.5% and 1 − β ≥ 90%, at expected sample size approximately 3,071 under H0 and 2,638 under H1. These threshold schedules are our own; they are not the schedules calibrated in the companion methodology paper, whose frontier holds the interim threshold at 0.999 with a near-nominal final threshold and a common futility threshold q = 0.90. They are evaluated from a single cache by a short user-defined loop that calls evaluate_design() with the per-look decision rule (a list of K per-look criteria passed to set_decision()).

cache_h0 <- build_cache(des, pri,
                        effect = list(theta_c = 0.33, theta_t = 0.33),
                        n_trials = 1e5, cores = 8, seed = 1L,
                        threshold_grid = list(efficacy = 0, futility = 0))
cache_h1 <- build_cache(des, pri,
                        effect = list(theta_c = 0.33, theta_t = 0.28),
                        n_trials = 1e5, cores = 8, seed = 1L,
                        threshold_grid = list(efficacy = 0, futility = 0))

p_stage <- c(0.997, 0.997, 0.997, 0.997, 0.980)
q_stage <- 0.85
dec_stage <- set_decision(
  efficacy = lapply(p_stage, function(p)
    list(list(threshold_effect = 0, threshold_prob = p))),
  futility = list(list(threshold_effect = 0, threshold_prob = q_stage)),
  futility_binding = TRUE)

oc_cal_h0 <- evaluate_design(cache_h0, dec_stage)   ## type I 2.42%, E(N | H0) ~ 3,071
oc_cal_h1 <- evaluate_design(cache_h1, dec_stage)   ## power  90.18%, E(N | H1) ~ 2,638

Comparator packages

The comparator rows in the table above were produced at the matched budget R = 10,000 with adaptr and BATSS. The calls are shown below:

Dependencies. The comparator snippets below are not part of adabay and are not run by it. Reproducing them requires adaptr and BATSS, which in turn requires INLA, to be installed; the adabay code on this page needs no additional packages.

adaptr

## adaptr comparator (matched budget R = 10,000, 8 cores).
## fixed_probs disables response-adaptive randomisation, giving a pure GSD;
## inferiority = 0.10 is adabay's binding futility P(theta_t - theta_c > 0) > 0.90.
spec <- adaptr::setup_trial_binom(
  arms            = c("control", "treatment"),
  true_ys         = c(0.33, 0.28),     # H1; use c(0.33, 0.33) for H0
  fixed_probs     = c(0.5, 0.5),
  data_looks      = c(760, 1520, 2280, 3040, 3800),
  control         = "control",
  superiority     = 0.99,
  inferiority     = 0.10,
  highest_is_best = FALSE,
  soften_power    = 1)

res <- adaptr::run_trials(spec, n_rep = 10000, base_seed = 1L, cores = 8)
summary(res)                           # type I / power and expected sample size

BATSS

## BATSS comparator (matched budget R = 10,000, 8 mclapply workers).
## batss.glm has no base_seed argument, so the L'Ecuyer stream is set here.
## Attached, not just namespace-qualified: batss.glm() takes BATSS's bare
## helpers (alloc.balanced, eff.arm.simple, ...), which need it on the path.
library(BATSS)
INLA::inla.setOption(num.threads = "1:1")
RNGkind("L'Ecuyer-CMRG"); set.seed(1L)

## With H0 = TRUE a single call returns BOTH hypotheses: $H1 uses the supplied
## beta, and $H0 forces the target coefficient to zero.
res <- BATSS::batss.glm(
  model       = y ~ group,
  var         = list(y = rbinom, group = alloc.balanced),
  var.control = list(y = list(size = 1)),
  family      = "binomial", link = "logit",
  beta        = c(qlogis(0.33), qlogis(0.28) - qlogis(0.33)),
  which       = 2, alternative = "less",
  R           = 10000, N = 3800,
  interim     = list(recruited = c(760, 1520, 2280, 3040)),
  prob0       = c(control = 0.5, treatment = 0.5),
  delta.eff   = 0, delta.fut = 0,
  eff.arm     = eff.arm.simple, eff.arm.control = list(b = 0.99),
  fut.arm     = fut.arm.simple, fut.arm.control = list(b = 0.10),
  eff.trial   = eff.trial.all,  fut.trial = fut.trial.all,
  H0          = TRUE,
  computation = "parallel", mc.cores = 8)

## type is "1" for an efficacy stop, "2" for futility, "0" for no decision.
mean(res$H0$sample$type == "1")                          # type I error rate
mean(res$H1$sample$type == "1")                          # power
mean(res$H0$sample$control + res$H0$sample$treatment)    # E(N) | H0
mean(res$H1$sample$control + res$H1$sample$treatment)    # E(N) | H1

What this exercises

  • The beta–binomial conjugate update; the posterior tail probability of the risk difference is computed by a fixed 64-node Gauss–Legendre quadrature.
  • Binding futility and a single-criterion efficacy rule.
  • The caching and calibration architecture.
