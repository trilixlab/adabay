ADRENAL re-design (binary endpoint)

Five-look Bayesian GSD on the risk-difference scale. Section 5.2 of the manuscript.

Setting

The ADRENAL trial (Venkatesh et al., NEJM 2018) was a multicentre, placebo-controlled, double-blind, randomised clinical trial of hydrocortisone versus placebo in patients with septic shock. The primary endpoint was 90-day all-cause mortality. With a 33% mortality rate in the placebo arm, the trial was powered to detect an absolute risk reduction of 5% at a two-sided 5% significance level, which required a maximum sample size of 3,800 (1,900 per arm with 1% dropout).

We re-implement the trial as a five-look Bayesian GSD (K = 5), with looks equally spaced at n = 380, 760, 1,140, 1,520, 1,900 patients per arm, independent Beta(1, 1) priors on the per-arm rates, a single-criterion efficacy rule 𝒫(Δ < 0 | ·) > 0.99 on the risk-difference scale, and a futility rule 𝒫(Δ > 0 | ·) > 0.90.

adabay call sequence

library(adabay)

des <- set_design(endpoint     = "binary",
                  n_per_look   = c(760, 1520, 2280, 3040, 3800),
                  effect_scale = "risk_difference",
                  alternative  = "less")

pri <- set_prior(endpoint = "binary",
                 arms = list(c = list(family = "beta", a = 1, b = 1),
                             t = list(family = "beta", a = 1, b = 1)))

dec <- set_decision(
  efficacy = list(list(threshold_effect = 0, threshold_prob = 0.99)),
  futility = list(list(threshold_effect = 0, threshold_prob = 0.90)),
  futility_binding = TRUE)

oc_h0 <- evaluate_design(des, pri, dec,
                         effect   = list(theta_c = 0.33, theta_t = 0.33),
                         n_trials = 1e6, cores = 8, seed = 1L)
oc_h1 <- evaluate_design(des, pri, dec,
                         effect   = list(theta_c = 0.33, theta_t = 0.28),
                         n_trials = 1e6, cores = 8, seed = 1L)

Operating characteristics

At R = 106 virtual trials per scenario the design reaches a type I error rate of 3.12% and a power of 87.74%, with an expected sample size of 2,202 patients across both arms under H1.

adabay runs on 8 CPU cores via mclapply with the L'Ecuyer combined multiple-recursive generator (cores = 8); adaptr on 8 cores via its native parallel backend; BATSS with 8 mclapply workers and INLA pinned to one thread per worker. Since the three simulation-based packages all run on 8 cores at the matched R = 10,000 budget, their wall-clock times are directly comparable at equal parallelism: the per-virtual-trial speedups on the binary case are approximately 31× versus adaptr (between one and two orders of magnitude) and 1.6 × 104 × versus BATSS (four orders of magnitude). “n/a” marks comparators that do not support this endpoint type (gsbDesign is restricted to the normal–normal continuous setting).

Threshold calibration

The companion methodology paper calibrates a five-look design with stage-specific efficacy thresholds p1:5 = (0.997, 0.997, 0.997, 0.997, 0.980) and common futility threshold q = 0.85, achieving type I error 2.44% and power 90.32% under the regulatory targets α ≤ 2.5% and 1 − β ≥ 90%, at expected sample size approximately 3,073 under H0 and 2,636 under H1. These stage-specific schedules are reproduced from a single cache by a short user-defined loop that calls evaluate_design() with the per-look decision rule (a list of K per-look criteria passed to set_decision()).

cache_h0 <- build_cache(des, pri,
                        effect = list(theta_c = 0.33, theta_t = 0.33),
                        n_trials = 1e5, cores = 8, seed = 1L,
                        threshold_grid = list(efficacy = 0, futility = 0))
cache_h1 <- build_cache(des, pri,
                        effect = list(theta_c = 0.33, theta_t = 0.28),
                        n_trials = 1e5, cores = 8, seed = 1L,
                        threshold_grid = list(efficacy = 0, futility = 0))

cal <- calibrate_design(
  cache         = cache_h0, cache_alt = cache_h1,
  alpha_target  = 0.025,
  power_target  = 0.90,
  efficacy_grid = seq(0.95, 0.999, by = 0.001),
  futility_grid = seq(0.80, 0.95,  by = 0.01)
)
print(cal$best)

Direct simulation vs. cached grid evaluation

What this exercises

  • The beta–binomial conjugate update; the posterior tail probability of the risk difference is computed by a fixed 64-node Gauss–Legendre quadrature.
  • Binding futility and a single-criterion efficacy rule.
  • The caching and calibration architecture.
