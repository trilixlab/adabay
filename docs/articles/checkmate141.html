CheckMate-141 HNSCC trial (time-to-event endpoint)

Event-driven five-look Bayesian GSD on the log-hazard-ratio scale, with Poisson recruitment. Section 5.4 of the manuscript.

Setting

CheckMate-141 (Ferris et al., NEJM 2016;375:1856–1867) was an open-label phase III randomised trial of nivolumab versus investigator's choice of single-agent chemotherapy (methotrexate, docetaxel or cetuximab) in adults with recurrent or metastatic squamous-cell carcinoma of the head and neck (HNSCC) whose disease had progressed within six months after platinum-based chemotherapy. The primary endpoint was overall survival. The trial randomised 361 patients in a 2:1 allocation, accrued 218 deaths at the planned interim analysis and was stopped early for benefit, with median overall survival 7.5 months for nivolumab versus 5.1 months for chemotherapy and a hazard ratio of Δ* = λt / λc = 0.70 (97.73% CI 0.51–0.96).

We re-implement CheckMate-141 as a five-look event-driven Bayesian GSD (K = 5) under a 1:1 allocation (a simplifying assumption for design-stage exposition, with the actual 2:1 randomisation accommodated by setting allocation_ratio = 2 in set_design()), with looks at cumulative events Dk = 50, 100, 150, 200, 250, hazards λc = log 2 / 5.1 = 0.1359 and λt = log 2 / 7.5 = 0.0924 events per month under H1, weakly informative λa ~ Gamma(1, 1) priors on the per-arm hazard rates, a single-criterion efficacy rule 𝒫(log Δ < 0 | ·) > 0.99 on the log-hazard-ratio scale and a futility rule 𝒫(log Δ > 0 | ·) > 0.90. Recruitment is modelled as a homogeneous Poisson process with rate r = 12.8 patients per month per arm, consistent with the CheckMate-141 enrolment timeline.

adabay call sequence

library(adabay)

des <- set_design(endpoint     = "tte",
                  d_total      = 250,
                  d_per_look   = c(50, 100, 150, 200, 250),
                  effect_scale = "log_hazard_ratio",
                  alternative  = "less")

pri <- set_prior(endpoint = "tte",
                 arms = list(c = list(family = "gamma", a = 1, b = 1),
                             t = list(family = "gamma", a = 1, b = 1)))

dec <- set_decision(
  efficacy = list(list(threshold_effect = 0, threshold_prob = 0.99)),
  futility = list(list(threshold_effect = 0, threshold_prob = 0.90)),
  futility_binding = TRUE)

acc <- set_accrual(model = "poisson", rate = 25.6)

oc_h0 <- evaluate_design(des, pri, dec,
                         effect  = list(lambda_c = log(2) / 5.1,
                                        lambda_t = log(2) / 5.1),
                         accrual = acc,
                         n_trials = 1e6, cores = 8, seed = 1L)
oc_h1 <- evaluate_design(des, pri, dec,
                         effect  = list(lambda_c = log(2) / 5.1,
                                        lambda_t = log(2) / 7.5),
                         accrual = acc,
                         n_trials = 1e6, cores = 8, seed = 1L)

Operating characteristics

At R = 106 virtual trials per scenario the re-design reaches a type I error rate of 3.10% and a power of 80.59%, with an expected number of events of 159 at trial stop under H1 (versus the fixed-sample target of 250) and an expected calendar duration of 12.78 months from randomisation of the first subject to the analysis at which the trial stops.

adabay runs on 8 CPU cores via mclapply with the L'Ecuyer combined multiple-recursive generator (cores = 8). “n/a” indicates that no faithful comparator is constructible for the time-to-event endpoint: BATSS's sole model interface batss.glm is GLM-only and cannot construct the censored event-time response an INLA survival likelihood requires (with the event-driven look schedule a further obstacle); adaptr covers only continuous and binary outcomes; and gsbDesign is restricted to the normal–normal continuous setting. Type I error is evaluated at λt / λc = 1 (equal median overall survival of 5.1 months in both arms) and power at λt / λc = 0.68 (control median 5.1 months versus treatment median 7.5 months, the CheckMate-141 hazard-ratio target). E(T | H1) is the expected calendar duration from randomisation of the first subject to the analysis at which the trial stops, in months, obtained as the direct Monte Carlo mean, across the simulated trials, of the realised stopping-look calendar time under Poisson recruitment.

What this exercises

  • The gamma–exponential conjugate update on the log-hazard-ratio scale; closed-form posterior tail probability via a beta CDF.
  • Event-driven look schedules via d_per_look in set_design().
  • Homogeneous Poisson recruitment via set_accrual(), with the expected calendar duration obtained as the direct Monte Carlo mean of the realised stopping-look calendar time.
Reproduce. The full script is shipped with the package as inst/examples/checkmate141.R.
