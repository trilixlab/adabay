TRANSFORM-2 esketamine re-design (continuous endpoint)

Five-look Bayesian GSD on the mean-difference scale. Section 5.1 of the manuscript.

Setting

TRANSFORM-2 (Popova et al., Am J Psychiatry 2019;176:428–438) was a phase III double-blind, active-controlled, randomised trial of flexibly dosed esketamine nasal spray plus a newly initiated oral antidepressant against placebo nasal spray plus a newly initiated oral antidepressant in adults with treatment-resistant depression. The primary endpoint was the change from baseline in the Montgomery–Åsberg Depression Rating Scale (MADRS, range [0, 60]) total score at Day 28 of the four-week induction phase. The trial randomised 227 patients in a 1:1 ratio and reported a mean MADRS change of −19.8 in the esketamine arm versus −15.8 in the placebo arm, with a treatment-versus-control difference of −4.0 (95% CI −7.31 to −0.64, p = 0.020). Esketamine nasal spray was subsequently approved for treatment-resistant depression.

Bayesian GSD re-design

We re-implement TRANSFORM-2 as a five-look Bayesian GSD (K = 5) on the mean-difference scale. The data-generating model has μc = −15.8 in the placebo arm and μt = −19.8 in the esketamine arm, with a common within-arm standard deviation σ = 13 on the MADRS-change scale (consistent with TRANSFORM-2's per-arm dispersion). The clinically relevant effect is Δ* = μt − μc = −4, with ΔH0 = 0. The fixed-sample design at α = 0.025 (one-sided) and 1 − β = 0.90 requires n = 222 patients per arm. The five-look GSD has looks equally spaced at n = 45, 89, 133, 177, 222 patients per arm, weakly informative priors μa ~ N(−10, 106) in both arms, a single-criterion efficacy rule ℙ(Δ < 0 | ·) > 0.99 and a futility rule ℙ(Δ > 0 | ·) > 0.90.

adabay call sequence

Design, prior and decision rule

library(adabay)

des <- set_design(endpoint     = "continuous",
                  n_per_look   = c(90, 178, 266, 354, 444),
                  effect_scale = "mean_difference",
                  alternative  = "less",
                  sigma        = 13)

pri <- set_prior(endpoint = "continuous",
                 arms = list(c = list(family = "normal", mean = -10, sd = 1e3),
                             t = list(family = "normal", mean = -10, sd = 1e3)))

dec <- set_decision(
  efficacy = list(list(threshold_effect = 0, threshold_prob = 0.99)),
  futility = list(list(threshold_effect = 0, threshold_prob = 0.90)),
  futility_binding = TRUE)

oc_h0 <- evaluate_design(des, pri, dec,
                         effect   = list(mu_c = -15.8, mu_t = -15.8),
                         n_trials = 1e6, cores = 8, seed = 1L)
oc_h1 <- evaluate_design(des, pri, dec,
                         effect   = list(mu_c = -15.8, mu_t = -19.8),
                         n_trials = 1e6, cores = 8, seed = 1L)

print(oc_h1)
plot(oc_h1)

Extracting the operating characteristics

The returned adabay_oc objects carry every quantity in the table below:

oc_h1$eff_prob               # power
oc_h0$expected_sample_size   # E(N | H0)

oc_h1$fut_prob_at_look       # beta_k  under H1

## Or all of the above as one tidy row per scenario
summarise_oc(list(oc_h0, oc_h1))

Operating characteristics

At R = 106 virtual trials per scenario the re-design reaches a type I error rate of 3.09% and a power of 85.59%, with an expected sample size of 265 patients across both arms under H1 (compared with the fixed-sample maximum of 444 across both arms).

adabay runs on 8 CPU cores via mclapply with the L'Ecuyer combined multiple-recursive generator (cores = 8); adaptr on 8 cores via its native parallel backend; gsbDesign analytic on a single core; BATSS with 8 mclapply workers and INLA pinned to one thread per worker. Type I error is evaluated at μt − μc = 0 and power at μt − μc = −4 (the observed TRANSFORM-2 mean-difference effect). All three simulation-based tools and the analytic gsbDesign reference agree within Monte Carlo error.

Comparator packages

The adaptr and BATSS rows in the table above were produced at the matched budget R = 10,000; gsbDesign is analytic and has no simulation budget. The calls are shown below:

Dependencies. The comparator snippets below are not part of adabay and are not run by it. Reproducing them requires adaptr, gsbDesign and BATSS, which in turn requires INLA, to be installed; the adabay code on this page needs no additional packages.

adaptr

## adaptr comparator (matched budget R = 10,000, 8 cores).
## fixed_probs disables response-adaptive randomisation, giving a pure GSD;
## inferiority = 0.10 is adabay's binding futility P(mu_t - mu_c > 0) > 0.90.
spec <- adaptr::setup_trial_norm(
  arms            = c("control", "treatment"),
  true_ys         = c(-15.8, -19.8),   # H1; use c(-15.8, -15.8) for H0
  sds             = c(13, 13),
  fixed_probs     = c(0.5, 0.5),
  data_looks      = c(90, 178, 266, 354, 444),
  control         = "control",
  superiority     = 0.99,
  inferiority     = 0.10,
  highest_is_best = FALSE,
  soften_power    = 1)

res <- adaptr::run_trials(spec, n_rep = 10000, base_seed = 1L, cores = 8)
summary(res)                           # type I / power and expected sample size

gsbDesign

## gsbDesign analytic comparator (numerical integration, single core).
## gsbDesign scores the UPPER tail, so the analysis is on delta' = control - treatment;
## treatment benefit is then delta' > 0 and the truths are H0 = 0, H1 = +4.
design <- gsbDesign::gsbDesign(
  nr.stages         = 5,
  patients          = matrix(c(45, 44, 44, 44, 45), ncol = 1),  # per-stage increment per arm
  sigma             = 13,
  criteria.success  = c(0, 0.99),
  criteria.futility = c(0, 0.90),
  prior.difference  = "non-informative")

sim <- gsbDesign::gsbSimulation(
  truth       = c(0, 4),
  type.update = "treatment effect",
  method      = "numerical integration",
  grid.type   = "manually")

x <- gsbDesign::gsb(design = design, simulation = sim)

gsbDesign::tab(x, "success", atDelta = c(0, 4))               # type I and power
gsbDesign::tab(x, "cumulative futility", atDelta = c(0, 4))
gsbDesign::tab(x, "sample size", atDelta = c(0, 4))           # expected sample size

BATSS

## BATSS comparator (matched budget R = 10,000, 8 mclapply workers).
## batss.glm has no base_seed argument, so the L'Ecuyer stream is set here.
## Attached, not just namespace-qualified: batss.glm() takes BATSS's bare
## helpers (alloc.balanced, eff.arm.simple, ...), which need it on the path.
library(BATSS)
INLA::inla.setOption(num.threads = "1:1")
RNGkind("L'Ecuyer-CMRG"); set.seed(1L)

## With H0 = TRUE a single call returns BOTH hypotheses: $H1 uses the supplied
## beta, and $H0 forces the target coefficient to zero.
res <- BATSS::batss.glm(
  model       = y ~ group,
  var         = list(y = rnorm, group = alloc.balanced),
  var.control = list(y = list(sd = 13)),
  family      = "gaussian", link = "identity",
  beta        = c(-15.8, -4),
  which       = 2, alternative = "less",
  R           = 10000, N = 444,
  interim     = list(recruited = c(90, 178, 266, 354)),
  prob0       = c(control = 0.5, treatment = 0.5),
  delta.eff   = 0, delta.fut = 0,
  eff.arm     = eff.arm.simple, eff.arm.control = list(b = 0.99),
  fut.arm     = fut.arm.simple, fut.arm.control = list(b = 0.10),
  eff.trial   = eff.trial.all,  fut.trial = fut.trial.all,
  H0          = TRUE,
  computation = "parallel", mc.cores = 8)

## type is "1" for an efficacy stop, "2" for futility, "0" for no decision.
mean(res$H0$sample$type == "1")                          # type I error rate
mean(res$H1$sample$type == "1")                          # power
mean(res$H0$sample$control + res$H0$sample$treatment)    # E(N) | H0
mean(res$H1$sample$control + res$H1$sample$treatment)    # E(N) | H1

What this exercises

  • The normal–normal closed-form per-look posterior of the mean difference.
  • A weakly informative conjugate prior in its natural parameterisation, anchored at the placebo mean.
  • Binding futility and a single-criterion efficacy rule.
Reproduce. The full script is shipped with the package as inst/examples/transform2.R.
