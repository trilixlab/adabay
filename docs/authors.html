How to cite adabay

If you use adabay in published work, please cite both the software paper and the methodology paper:

Software paper

He Z, Yu F (2026).
adabay: an R package for rapid evaluation and calibration of Bayesian
group sequential designs across common endpoint types.
R package version 0.1.0. arXiv preprint (forthcoming).
URL https://github.com/trilixlab/adabay.

Methodology paper

He Z, Yu F, Cro S, Billot L (2026).
Rapid evaluation and calibration of Bayesian group sequential designs
via conjugate-mixture semi-simulation.
arXiv preprint arXiv:2509.05537. (Companion methodology paper.)
URL https://arxiv.org/abs/2509.05537.

BibTeX

@Misc{adabay2026,
  title    = {{adabay}: an {R} package for rapid evaluation and calibration of {B}ayesian group sequential designs across common endpoint types},
  author   = {Zhangyi He and Feng Yu},
  year     = {2026},
  note     = {R package version 0.1.0. arXiv preprint (forthcoming).},
  url      = {https://github.com/trilixlab/adabay}
}

@Misc{adabayMethodology2026,
  title    = {Rapid evaluation and calibration of {B}ayesian group sequential designs via conjugate-mixture semi-simulation},
  author   = {Zhangyi He and Feng Yu and S. Cro and L. Billot},
  year     = {2026},
  note     = {arXiv preprint arXiv:2509.05537. Companion methodology paper.},
  url      = {https://arxiv.org/abs/2509.05537}
}

Inside R, run citation("adabay") to obtain the formatted citation entries.
