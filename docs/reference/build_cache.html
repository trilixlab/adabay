build_cache()

Build a precomputation cache for grid evaluation.

Description

Implements the precomputation strategy: simulates trials once at the union of all candidate look times, and caches per-look posterior tail probabilities at the union of all candidate effect-size thresholds. The cache decouples the expensive simulation pass from threshold and look-time selection, so any specific design configuration can subsequently be evaluated by evaluate_design() or calibrate_design() in milliseconds.

Usage
build_cache(
  design,
  prior,
  effect,
  accrual                 = NULL,
  n_trials                = 10000L,
  cores                   = 1L,
  seed                    = NULL,
  threshold_grid          = NULL,
  cross_core_reproducible = FALSE
)
Arguments
design
A adabay_design carrying the union of all candidate look times.
prior
A adabay_prior.
effect
Data-generating values (named list), as for evaluate_design().
accrual
Optional set_accrual() specification. Required for time-to-event designs, whose staggered Poisson recruitment drives the calendar-time exposure cutoff. When supplied (any endpoint) it is stored in the cache so that evaluate_design() on the cache reports the expected duration.
n_trials
Number of virtual trials to simulate.
cores
Number of CPU cores.
seed
Optional integer seed for reproducibility.
threshold_grid
Named list with elements efficacy and futility, each a numeric vector of effect-size thresholds e and f at which per-look tail probabilities are cached.
cross_core_reproducible
Logical, default FALSE. When TRUE, the simulator runs in a single driver process (the supplied cores is ignored for the simulation pass) so the cached per-trial RNG draws are bit-identical across worker counts.
Value

An object of class "adabay_cache". print() displays the simulation budget, the union of look times, and the union of effect-size thresholds.

Memory footprint

The cache stores per-look tail probabilities at every virtual trial and effect-size threshold. For R virtual trials, K candidate look times and NT unique effect-size thresholds, the cache holds approximately 8·R·K·NT bytes. For R=105, K=5, NT=3 the cache is roughly 12 MB.

Examples
## Build a cache, then score two threshold combinations in milliseconds
cache <- build_cache(
  design   = des,
  prior    = pri,
  effect   = list(theta_c = 0.33, theta_t = 0.28),
  n_trials = 1e5,
  cores    = 1,
  seed     = 1L,
  threshold_grid = list(
    efficacy = c(0.0, -0.05),
    futility = 0.0
  )
)

oc_a <- evaluate_design(cache, decision = dec_a)
oc_b <- evaluate_design(cache, decision = dec_b)
