calibrate_design()

Calibrate design thresholds against operating-characteristic targets.

Description

Searches a user-supplied grid of posterior-probability thresholds (p, q) against a precomputed adabay_cache under target (α, 1−β) constraints, and returns the design that meets the targets while minimising the expected sample size. Two caches are required: cache built under H0 (drives the type I error rate of every grid point) and cache_alt built under H1 (drives the power and expected sample size).

Usage
calibrate_design(
  cache,
  cache_alt,
  alpha_target     = 0.025,
  power_target     = 0.90,
  efficacy_grid,
  futility_grid    = c(1),
  futility_binding = FALSE
)
Arguments
cache
A adabay_cache object built under H0 (drives the type I error rate of every grid point).
cache_alt
A second adabay_cache object built under H1 (drives the power and expected sample size of every grid point). Required: a calibration is a constrained search over both targets and cannot be carried out from a single cache.
alpha_target
Type I error rate upper bound; default 0.025 (one-sided).
power_target
Power lower bound; default 0.90.
efficacy_grid
Numeric vector of efficacy posterior-probability thresholds p.
futility_grid
Numeric vector of futility posterior-probability thresholds q. The value c(1) disables futility stopping for that grid cell.
futility_binding
Logical; whether the futility rule binds for the type I error calculation.
Value

A list with elements best (a adabay_oc for the calibrated design) and grid (a data frame with one row per threshold combination and columns p, q, α, power, expected sample size, etc.).

Examples
## Calibrate the ADRENAL re-design against alpha = 0.025, power = 0.90
cache_h0 <- build_cache(des, pri, effect = list(theta_c = 0.33, theta_t = 0.33),
                        n_trials = 1e5, seed = 1L,
                        threshold_grid = list(efficacy = 0, futility = 0))
cache_h1 <- build_cache(des, pri, effect = list(theta_c = 0.33, theta_t = 0.28),
                        n_trials = 1e5, seed = 1L,
                        threshold_grid = list(efficacy = 0, futility = 0))

cal <- calibrate_design(
  cache         = cache_h0,
  cache_alt     = cache_h1,
  alpha_target  = 0.025,
  power_target  = 0.90,
  efficacy_grid = seq(0.95, 0.999, by = 0.001),
  futility_grid = seq(0.80, 0.95,  by = 0.01)
)

print(cal$best)
head(cal$grid)
