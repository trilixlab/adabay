fit_mixture()

Approximate a non-conjugate prior by a finite mixture of conjugate components.

Description

Fits a finite mixture of conjugate components (beta, normal, or gamma, depending on the endpoint) to a user-supplied prior by minimisation of the empirical forward Kullback–Leibler divergence, with an elbow rule for component selection. When the suggested RBesT package is available, the fit is delegated to RBesT::automixfit() for robust kernel-specific EM updates; otherwise a built-in beta-kernel EM fallback is used. Returns per-quantile tail-probability diagnostics and emits a runtime warning when the maximum absolute tail-probability error exceeds tol_tail. The print() method prints the per-quantile error table; the plot() method overlays the empirical-sample density on the fitted mixture density together with rugs at the tail thresholds.

Usage
fit_mixture(
  endpoint,
  arm,
  prior,
  n_components_max = 5L,
  tol_kl           = 1e-3,
  tol_tail         = 5e-3,
  tail_quantiles   = c(0.025, 0.05, 0.10, 0.50, 0.90, 0.95, 0.975),
  n_samples        = 10000L,
  seed             = NULL
)
Arguments
endpoint
Endpoint type. Determines the conjugate kernel used in the mixture.
arm
"c" (control) or "t" (treatment).
prior
Density function or numeric vector of samples drawn from the user-specified prior.
n_components_max
Maximum number of mixture components to try; default 5.
tol_kl
Tolerance for the elbow rule on the relative KL decrement (component selection).
tol_tail
Tolerance on the maximum absolute tail-probability error at the quantile grid tail_quantiles. A warning is emitted when this tolerance is exceeded.
tail_quantiles
Quantile grid used to compute the empirical tail-probability error table.
n_samples
Number of prior samples drawn when prior is supplied as a function.
seed
Optional integer seed. When prior is a density function, sample generation draws from the ambient RNG stream by default; passing a seed makes the fitted mixture reproducible.
Value

An object of class adabay_prior_arm, suitable for passing to set_prior(), with attributes carrying the per-component fit, the Kullback–Leibler divergence, the per-quantile tail-error table, and the empirical samples used for the overlay plot.

Tail-safety diagnostic. Forward KL is mass-covering, so a small fitted divergence guarantees that the bulk of the fitted mixture is close to the target prior but does not, on its own, guarantee that it matches in the tails. Because stopping decisions are driven by posterior tail probabilities, fit_mixture() always computes a per-quantile tail-probability error table and warns if the maximum absolute error exceeds tol_tail.
Examples
## Logit-normal prior on the control rate, approximated by a beta mixture
pri_c <- fit_mixture(
  endpoint = "binary", arm = "c",
  prior    = function(theta) dlnorm(theta / (1 - theta),
                                    meanlog = -0.7, sdlog = 0.4),
  n_components_max = 5,
  tol_kl   = 1e-3,
  tol_tail = 5e-3
)

print(pri_c)   # selected L, KL, per-quantile tail-error table
plot(pri_c)    # empirical-sample density vs fitted mixture density
