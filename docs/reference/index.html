Function reference

All exported functions, S3 classes and methods in adabay 0.1.0.

Design specification

set_design() Specify the design skeleton: endpoint, look schedule, effect scale.
set_prior() Specify per-arm priors (conjugate, or a mixture from fit_mixture()).
set_decision()Specify per-look efficacy and futility decision rules.
set_accrual() Specify recruitment, follow-up and dropout.
fit_mixture() Approximate a non-conjugate prior by a conjugate mixture.

Simulation and evaluation

build_cache() Cache per-look tail probabilities over a grid of look times and thresholds.
evaluate_design()Evaluate operating characteristics; polymorphic over adabay_design (fused simulate-and-aggregate path) and adabay_cache (cheap aggregation from a pre-built cache).
calibrate_design()Search a threshold grid for target operating characteristics.
summarise_oc() Tidy summary across one or more adabay_oc objects.

S3 classes

adabay_design Design specification returned by set_design().
adabay_prior Joint prior specification returned by set_prior().
adabay_prior_arm Per-arm mixture-of-conjugate prior returned by fit_mixture().
adabay_decision Decision-rule specification returned by set_decision().
adabay_accrual Accrual specification returned by set_accrual().
adabay_cache Cache of per-look tail probabilities returned by build_cache().
adabay_oc Operating characteristics returned by evaluate_design(); also carried as $oc_h0 / $oc_h1 inside the $best element returned by calibrate_design().
adabay_calibration Threshold calibration returned by calibrate_design(), carrying $best and the full $grid.
adabay_calibration_best Selected calibrated design (chosen thresholds with type I and power) in the $best element of an adabay_calibration.

S3 methods

print() Compact textual summary for every adabay_* class.
plot() Stopping-probability bar chart for adabay_oc; density-overlay plot for adabay_prior_arm.
summary() Detailed numeric summary for adabay_oc.
