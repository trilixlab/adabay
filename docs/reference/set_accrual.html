set_accrual()

Set accrual: recruitment, follow-up and dropout.

Description

Configures the recruitment process and the per-patient follow-up duration used in computing the expected study duration; the follow-up term enters the reported duration for the sample-size-driven continuous and binary schedules only, not the exposure-driven count schedule or the event-driven time-to-event schedule. Three recruitment models are supported out of the box: a homogeneous Poisson process, a piecewise-constant Poisson process, and an arbitrary user-supplied callback. Per-patient follow-up is a single non-negative numeric duration; a function-valued follow_up is not supported in this release. dropout and dropout_rate are validated and stored for forward compatibility, but are not consumed by any simulator or reported quantity in this release.

Usage
set_accrual(
  model         = c("poisson", "piecewise", "callback"),
  rate          = NULL,
  breakpoints   = NULL,
  callback      = NULL,
  follow_up     = 0,
  dropout       = c("none", "exponential"),
  dropout_rate  = NULL
)
Arguments
model
Recruitment model: "poisson" (homogeneous), "piecewise" (piecewise-constant with breakpoints) or "callback" (user-supplied). Only "poisson" affects the reported expected duration: the other models are accepted for specification, but expected_duration is returned as NA for them, and time-to-event designs require "poisson" outright.
rate
Recruitment rate, pooled across both arms; split into per-arm rates by the design's allocation_ratio. For "piecewise", a numeric vector with one rate per segment.
breakpoints
Calendar-time breakpoints for "piecewise"; numeric vector of length one less than the number of segments.
callback
User-supplied function returning recruitment times when model = "callback".
follow_up
Per-patient follow-up duration: a single non-negative numeric. A function-valued follow_up is not supported in this release and is rejected with an informative error.
dropout
"none" (the default) or "exponential". Stored only; not consumed in this release.
dropout_rate
Per-arm dropout rate when dropout = "exponential".
Value

An object of class "adabay_accrual".

Examples
## Homogeneous Poisson recruitment, no dropout
acc <- set_accrual(model = "poisson", rate = 40)

## Piecewise-constant recruitment with two segments
acc <- set_accrual(
  model       = "piecewise",
  rate        = c(5, 20),
  breakpoints = 3
)

## Exponential dropout
acc <- set_accrual(
  model        = "poisson",
  rate         = 20,
  dropout      = "exponential",
  dropout_rate = 0.01
)
