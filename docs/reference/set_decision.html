set_decision()

Set per-look decision rules.

Description

Defines posterior-probability efficacy and futility stopping rules for a Bayesian group sequential design. Each rule is a list of one or more criteria, all of which must fire jointly for the rule to trigger, so single-, dual- and higher-criterion rules are expressible in the same syntax. Binding and non-binding futility are both supported.

Usage
set_decision(
  efficacy,
  futility         = NULL,
  futility_binding = FALSE
)
Arguments
efficacy
List of efficacy criteria, or a list of such lists (one per look). Each criterion is a list with elements threshold_effect (the effect-size threshold – ek,u) and threshold_prob (the posterior-probability threshold – pk,u).
futility
List of futility criteria, in the same shape as efficacy; NULL disables futility stopping.
futility_binding
Logical. If FALSE (the regulatory default), the reported type I error rate is the rate that would be observed if the futility rule had been ignored.
Value

An object of class "adabay_decision".

Decision rule

At the k-th look the trial stops for efficacy if all Uk efficacy criteria are simultaneously met, 𝒫(Δ > ek,u | 𝒟k) > pk,u for every u, and for futility if all Vk futility criteria are simultaneously met, 𝒫(Δ < fk,v | 𝒟k) > qk,v for every v. The inequality direction is determined by the alternative argument of set_design(): the formulas above are for the default alternative = "greater"; with alternative = "less" (as in the four case-study articles), both the efficacy and futility inequalities mirror to 𝒫(Δ < ek,u | 𝒟k) > pk,u and 𝒫(Δ > fk,v | 𝒟k) > qk,v.

Examples
## Single-criterion efficacy and futility, common across looks
dec <- set_decision(
  efficacy = list(list(threshold_effect = 0, threshold_prob = 0.99)),
  futility = list(list(threshold_effect = 0, threshold_prob = 0.90)),
  futility_binding = FALSE
)

## Dual-criterion efficacy combining non-superiority and a clinically-relevant threshold
dec <- set_decision(
  efficacy = list(
    list(threshold_effect =  0.00, threshold_prob = 0.99),
    list(threshold_effect = -0.05, threshold_prob = 0.50)
  ),
  futility = list(list(threshold_effect = 0, threshold_prob = 0.90)),
  futility_binding = FALSE
)
