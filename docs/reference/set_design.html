set_design()

Set the Bayesian group sequential design skeleton.

Description

Declares the endpoint type, look schedule and effect scale of a two-arm Bayesian group sequential design. Returns a adabay_design S3 object that is then consumed by set_prior(), evaluate_design() and build_cache().

Usage
set_design(
  endpoint,
  n_per_look       = NULL,
  exposure_per_look = NULL,
  d_total          = NULL,
  d_per_look       = NULL,
  effect_scale     = NULL,
  alternative      = c("greater", "less"),
  delta_null       = NULL,
  sigma            = NULL,
  allocation_ratio = 1
)
Arguments
endpoint
One of "continuous", "binary", "count" or "tte" (time-to-event).
n_per_look
Cumulative sample size at each look, pooled across both arms (continuous and binary endpoints); the number of looks K is taken from its length. Split into per-arm targets by allocation_ratio.
exposure_per_look
Cumulative exposure at each look, pooled across both arms (count endpoint); split into per-arm targets by allocation_ratio.
d_total
Total target number of events (tte endpoint).
d_per_look
Cumulative number of events at each look (tte endpoint).
effect_scale
Effect-size parameterisation. Permitted values are "mean_difference" or "standardised_mean_difference" (continuous); "risk_difference", "risk_ratio" or "odds_ratio" (binary); "rate_difference", "rate_ratio" or "log_rate_ratio" (count); "hazard_ratio" or "log_hazard_ratio" (tte). Defaults are the first of each group: "mean_difference", "risk_difference", "rate_difference", "hazard_ratio".
alternative
"greater" for H1: Δ > Δ0 or "less" for H1: Δ < Δ0.
delta_null
Null-hypothesis effect-size value Δ0.
sigma
Common within-arm SD of the simulated outcome data. Required for every continuous design, since it drives the Monte Carlo data generation; additionally used by the known-variance normal prior.
allocation_ratio
Treatment-to-control allocation ratio (default 1). It splits n_per_look (continuous/binary) and exposure_per_look (count) into per-arm targets; for "tte" the pooled d_per_look/d_total event targets are left unchanged and the pooled recruitment rate is split into per-arm rates in this ratio instead.
Value

An object of class "adabay_design".

Examples
## Five-look binary GSD on the risk-difference scale (ADRENAL re-design)
des <- set_design(
  endpoint     = "binary",
  n_per_look   = c(760, 1520, 2280, 3040, 3800),
  effect_scale = "risk_difference",
  alternative  = "less"
)
print(des)

## Five-look tte GSD on the log-hazard-ratio scale
des <- set_design(
  endpoint     = "tte",
  d_total      = 508,
  d_per_look   = c(102, 204, 305, 407, 508),
  effect_scale = "log_hazard_ratio",
  alternative  = "less"
)
