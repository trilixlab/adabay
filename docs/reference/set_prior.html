set_prior()

Set per-arm priors for a Bayesian group sequential design.

Description

Constructs a prior specification matched to the endpoint of the design. Supports conjugate priors in their natural parameterisation, and finite mixtures of conjugate components obtained from fit_mixture().

Usage
set_prior(endpoint, arms)
Arguments
endpoint
Endpoint type matching the design: one of "continuous", "binary", "count" or "tte" (time-to-event).
arms
A named list with elements c and t, each giving the per-arm prior specification. A conjugate prior is supplied as a list with a family element ("normal", "normal_inverse_gamma", "beta", "gamma") and the corresponding hyperparameters. A mixture prior is supplied as a adabay_prior_arm object returned by fit_mixture().
Conjugate kernel by endpoint
EndpointConjugate kernelHyperparameters
Continuous (known σ2)normalmean, sd
Continuous (unknown σ2)normal_inverse_gammanu, kappa, alpha, beta
Binarybetaa, b
Countgammaa, b
Time-to-eventgammaa, b
Value

An object of class "adabay_prior".

Examples
## Independent Beta(1,1) on each arm (binary endpoint)
pri <- set_prior(
  endpoint = "binary",
  arms = list(c = list(family = "beta", a = 1, b = 1),
              t = list(family = "beta", a = 1, b = 1))
)

## Weakly informative Normal priors (continuous endpoint)
pri <- set_prior(
  endpoint = "continuous",
  arms = list(c = list(family = "normal", mean = 12, sd = 1e3),
              t = list(family = "normal", mean = 12, sd = 1e3))
)

## Mixture prior on the control arm from fit_mixture()
pri_c <- fit_mixture(endpoint = "binary", arm = "c",
                     prior    = function(theta) dnorm(log(theta / (1 - theta)),
                                                      mean = -0.7,
                                                      sd   = 0.4) / (theta * (1 - theta)))
pri <- set_prior(
  endpoint = "binary",
  arms = list(c = pri_c,
              t = list(family = "beta", a = 1, b = 1))
)
