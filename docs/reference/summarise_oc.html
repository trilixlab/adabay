summarise_oc()

Summarise operating characteristics in tidy form.

Description

Returns a tidy data frame summarising one or more adabay_oc objects. Convenient for comparing operating characteristics across designs in a grid, or across endpoints in a benchmark.

Usage
summarise_oc(x)
Arguments
x
A adabay_oc object or a list of them. When a list is supplied, names are used as a label column.
Value

A data.frame with one row per input adabay_oc and columns covering: per-look stopping probabilities, overall type I error or power, expected sample size and (if accrual was supplied) expected calendar duration.

Examples
## Compare several designs in one tidy data frame
oc_5look <- evaluate_design(des_5, pri, dec, effect = eff_h1, n_trials = 1e4, seed = 1L)
oc_3look <- evaluate_design(des_3, pri, dec, effect = eff_h1, n_trials = 1e4, seed = 1L)

tab <- summarise_oc(list(five_look = oc_5look, three_look = oc_3look))
print(tab)
